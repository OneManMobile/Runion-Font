# ─────────────────────────────────────────────────────────────────────
#  RUNION BASIC — glyph source
# ─────────────────────────────────────────────────────────────────────
#  The whole font lives on ONE grid of 3 × 7 points:
#
#        x:  0   1   2
#   y=6      ·   ·   ·     top
#   y=5      ·   ·   ·
#   y=4      ·   ·   ·
#   y=3      ·   ·   ·     middle
#   y=2      ·   ·   ·
#   y=1      ·   ·   ·
#   y=0      ·   ·   ·     baseline
#
#  point    = "xy"            e.g. 06 = top-left, 20 = bottom-right
#  stroke   = points joined by "-" (a polyline, corners are mitred)
#             first == last  → closed shape
#             a lone point   → a dot
#  RULE     : every letter and digit must touch x=0 AND x=2.
#  MARKS    : accents live outside the rune — two attic rows above (y = 7, 8) and
#             two cellar rows below (y = a, b  →  -1, -2). Every rune fills the same
#             box, so one mark position fits them all; accented letters (é ñ š ő …)
#             are never drawn: the build composes them from Unicode, rune + mark.
#  CAPITALS : never drawn separately — an UPPERCASE character reuses the
#             same dots and lines, traced with the heavier @cap_stroke.
#
#  line format:   name | characters | strokes
#  characters :   space separated · "t+h" = contraction (ligature, always on)
#                 "a~e" = optional contraction (OpenType ss01, off by default)
#                 "~ü"  = optional single swap (ss01): ü shows this rune instead
#                 U+XXXX allowed for awkward characters
#  strokes    :   "=name" reuses the strokes of a glyph defined above
# ─────────────────────────────────────────────────────────────────────

# ── Nordic ── made the medieval way: take a rune, strike it, or add to it ──
#   æ = ᛅ, the later Scandinavian a/æ rune: a stave struck by a rising stroke
#   ø = ᚯ, the medieval ø rune: the same stave struck twice   (ä ö share æ ø)
#       alt ø, o with a bar through its diamond:  00-24-16-04-20 04-24
#   å = "double a": ansuz with a third arm          (aa contracts to it)
#   ð = þ with a bar
#   ß = the older four-stroke Σ form of sowilo · ħ ł = h, l with one more stroke
#   ä ö ü are composed (rune + dots) like every accented letter; with ss01 they
#   become the sound-runes instead: ä → æ, ö → ø, ü → y — as medieval carvers wrote them
